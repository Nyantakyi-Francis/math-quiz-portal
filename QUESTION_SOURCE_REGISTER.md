# Question source register

## Purpose

This register tracks book-backed candidate areas for the eight draft modules. It is not a final question bank.

Use it to choose fresh WASSCE-style questions from the Aki-Ola books without copying the books verbatim. Each row identifies the source area, skill, likely final question style, and whether an image is needed.

## Current rule

- Prefer strong text-only and table-only exercises.
- Use a book diagram only if the crop passes quality checks.
- If a diagram fails quality checks, drop that diagram-based candidate and choose another exercise.
- Do not use AI freehand diagrams as final assets.
- Do not import a module until its selected questions, answer keys, explanations, and any images have been checked.
